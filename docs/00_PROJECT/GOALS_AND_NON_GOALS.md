# Goals and Non-Goals

## Goals

1. Demonstrate an end-to-end transaction investigation workflow.
2. Automate contextual evidence gathering.
3. Analyze transaction anomalies.
4. Detect suspicious account networks.
5. Produce a structured risk assessment.
6. Generate an evidence-grounded investigation report.
7. Validate report claims deterministically.
8. Provide a compliance analyst dashboard.
9. Maintain an auditable investigation trail.
10. Demonstrate the concept using public and synthetic datasets.

## Non-Goals

The current project plan does not define Sentinel AI as:

- a replacement for a bank's existing transaction monitoring system
- a fully deployed banking production system
- an autonomous replacement for compliance analysts
- a source of legal advice
- a system using real customer banking data during the prototype

## Prototype Boundary

Bank integrations are represented using mock APIs where specified.

The prototype should clearly distinguish simulated data and integrations from production implementations.
