# Feature — Network Analysis

## Purpose

Identify suspicious transaction relationships that cannot be understood from a single transaction.

## Technology

Neo4j.

## Patterns

- layering
- structuring
- shell-company behavior
- fraud rings

## Output

The feature produces structured network findings.

## Visualization

The dashboard presents relevant graph findings using the planned interactive network visualization.

## Provenance

Network findings retain graph query/source metadata and timestamps.
