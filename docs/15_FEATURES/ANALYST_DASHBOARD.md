# Feature — Analyst Dashboard

## Purpose

Provide the compliance analyst with a complete investigation view.

## Views

### Case Queue

List investigation cases.

### Case Detail

Show:

- transaction
- risk score
- evidence
- network
- report
- validation
- recommended action

### Network View

Interactive account relationship graph.

### Report View

Readable investigation report.

### Action Panel

Analyst decision controls.

## Audit

Every analyst confirmation must be logged with relevant analyst and timestamp information.
