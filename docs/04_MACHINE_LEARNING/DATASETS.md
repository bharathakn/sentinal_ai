# Datasets

## IEEE-CIS Fraud Detection Dataset

Purpose:

Primary training and evaluation dataset.

The project plan identifies approximately 590,540 transactions and a fraud rate of approximately 3.5%.

## PaySim

Purpose:

Supplementary fraud-pattern testing and network-related experimentation.

The project plan identifies approximately 6.3 million synthetic mobile-money transactions.

## Custom Synthetic India Dataset

Purpose:

Demonstrate India-relevant transaction patterns.

Planned characteristics include:

- UPI
- NEFT
- RTGS
- Indian transaction timing patterns
- project-defined regulatory thresholds
- synthetic fraud patterns

## Dataset Rules

- Do not represent synthetic data as real bank data.
- Document preprocessing.
- Document feature engineering.
- Document train/test methodology.
- Preserve reproducibility information.
- Record dataset versions where applicable.
