# Regulatory Mapping

## Purpose

Connect detected investigation patterns with the regulatory references defined by the project.

## Frameworks Referenced

The project plan identifies:

- FATF typologies
- RBI AML guidance
- FIU-IND reporting considerations

## Mapping Principle

A detected pattern should map only to references that have been explicitly approved and documented.

## Pattern Categories

The project plan identifies:

- layering
- structuring
- shell-company behavior
- fraud-ring behavior

## Auditability

For each regulatory match, retain:

- detected pattern
- regulatory reference
- mapping source
- case association

## Important

Regulatory references must not be invented by the LLM.

The current project mapping should be maintained separately from generated narrative text.
