# General Development Rules

* Read project instructions before making changes.
* Read relevant feature documentation before implementation.
* Do not invent requirements.
* Do not modify unrelated functionality.
* Reuse existing functionality where appropriate.
* Keep changes focused.
* Preserve documented architectural decisions.
* Test meaningful changes.
* Update documentation when durable project behavior changes.
* Never commit secrets.
