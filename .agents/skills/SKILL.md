# Project Planning Skill

## Purpose

Convert a project requirement into a clear implementation plan.

## Process

1. Read project instructions.
2. Read relevant architecture.
3. Read relevant feature documentation.
4. Inspect the current repository.
5. Identify affected areas.
6. Identify dependencies.
7. Identify risks.
8. Produce a focused implementation plan.
9. Wait for approval when the task requires architectural decisions.

## Rules

Do not implement while still determining the architecture unless explicitly requested.
